## GIAI ĐOẠN 1: THIẾT LẬP NỀN TẢNG THIẾT KẾ (DESIGN SYSTEM & ASSETS)

### Task 1.1: Cấu trúc thư mục Resources & Typography
* **Mục tiêu:** Cài đặt font chữ nhận diện thương hiệu thay thế font mặc định của hệ điều hành.
* **Tài nguyên cần thêm:**
  * Font tiêu đề: `PlayfairDisplay-Bold.ttf`, `PlayfairDisplay-Regular.ttf`
  * Font nội dung: `Inter-Regular.ttf`, `Inter-Medium.ttf`, `Inter-SemiBold.ttf`
  * Vị trí lưu: `src/main/resources/fonts/`
* **Triển khai trong Java:**
  * Load font động trong phương thức `init()` hoặc `start()` của `App.java`:
    ```java
    Font.loadFont(getClass().getResourceAsStream("/fonts/PlayfairDisplay-Bold.ttf"), 14);
    Font.loadFont(getClass().getResourceAsStream("/fonts/Inter-Regular.ttf"), 14);
    ```

### Task 1.2: Xây dựng File Stylesheet toàn cục (`theme.css`)
* **Mục tiêu:** Định nghĩa biến màu, lớp dùng chung, nút bấm và ô nhập liệu[cite: 1].
* **File tạo mới:** `src/main/resources/styles/theme.css`
* **Nội dung đặc tả:**
  * Bảng màu chuẩn:
    * Primary (Xanh rêu): `#172B23` (Active: `#233F34`)
    * Accent (Cam phục vụ): `#E88338`
    * Background (Be sáng): `#F3EFEA`
    * Card Background: `#FFFFFF`
    * Text Primary: `#1C1917`
    * Text Muted / Placeholder: `#78716C`
    * Border: `#E7E2DA`
  * Khử outline mặc định của focus trên JavaFX:
    ```css
    .text-input:focused, .button:focused {
        -fx-faint-focus-color: transparent;
        -fx-focus-color: -color-primary;
    }
    ```

## GIAI ĐOẠN 2: CHUẨN HÓA KHUNG ỨNG DỤNG & CỬA SỔ (WINDOW CHROME)

### Task 2.1: Loại bỏ Title Bar mặc định của OS
* **Hiện trạng cần sửa:** Giao diện bị đứt gãy do thanh tiêu đề trắng/xám và nút Close đỏ của Windows[cite: 2, 3, 4, 5, 6, 7, 8].
* **Thực hiện:**
  1. Trong `MainApp.java`, thiết lập `primaryStage.initStyle(StageStyle.UNDECORATED);`.
  2. Tạo Component `CustomHeader.fxml` (dùng chung cho mọi màn hình chính và dialog popup):
     * Chiều cao `prefHeight="36"`, nền trùng màu nền cha (`#F3EFEA` hoặc `#FFFFFF`).
     * Góc phải: Nút ẩn (`-`) và nút đóng (`✕`) có icon xám, hover đổi nền `#E5E0D8`.
     * Xử lý kéo thả cửa sổ: Bắt sự kiện `onMousePressed` và `onMouseDragged` trên Header Pane.
