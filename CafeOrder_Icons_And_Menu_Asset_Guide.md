# PHẦN 1: BẢNG TRA CỨU HỆ THỐNG ICON CẦN THIẾT

### 1. Quy chuẩn Kỹ thuật Icon (Asset Guidelines)
* **Phong cách:** Nét vẽ đơn sắc thanh mảnh (Outline / Line Stroke 1.5px – 2px). Tránh icon 3D bóng bẩy hoặc icon đặc ruột (filled) quá dày.
* **Bộ icon khuyến nghị:** **Lucide Icons** ([lucide.dev](https://lucide.dev)), **Feather Icons**, hoặc **Tabler Icons**.
* **Định dạng tối ưu:** File `.svg` (Vector) hoặc file `.png` nền trong suốt (Transparent background).
* **Màu sắc đề xuất:**
  * Màu chữ/icon thông thường: `#292722` (Charcoal tối) hoặc `#183C32` (Xanh rêu đậm).
  * Màu icon khi hover / active trên nút: `#FFFFFF` (Trắng tinh).
  * Màu icon phụ / placeholder: `#817B70` (Xám be ấm).
